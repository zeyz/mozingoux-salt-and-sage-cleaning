# Salt And Sage Cleaning

A fictional Eastern North Carolina business portfolio concept by MozingoUX. All contact details and prices are illustrative. No affiliation with any real business.

## Run
Serve this directory with `python3 -m http.server 8000`. No build or dependencies required. Deploy the root on GitHub Pages.

## Features
Responsive, semantic HTML, keyboard navigation, reduced-motion support, local-only interactive estimate/request experience. Forms do not send or store contact details.

## Photography
Local editorial photo downloaded from Unsplash; illustrative stock image, not business staff or premises.
